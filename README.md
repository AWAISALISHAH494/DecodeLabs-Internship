# To-Do List Application (Python CLI)

A simple command-line To-Do List application built using Python.  
It allows users to manage daily tasks with persistent storage using a JSON file.

---

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Automatic saving using JSON file
- Persistent data storage

---
## Technologies Used

- Python 3
- JSON (for data storage)
- File Handling (os module)
